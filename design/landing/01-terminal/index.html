Push the session. Pull the context.

Stash saves a coding agent’s working context so another agent can continue.

$ npm install -g @stash/cli

Three commands carry the context.

Claude Code on one laptop. Any agent on the next.

~ $ stash push

scanning for secrets     1 redacted

~ $ stash pull ses_8kq2v

A handoff says what happened.

A Briefing keeps the evidence, the failures and the rules.

--- a/handoff.md
+++ b/stash pull ses_8kq2v
  1. -fixed most of the auth bug, see the auth files
  2. +objective: find why logins fail intermittently
  3. +discovery: refresh fires twice under load, evidenced in e_014
  4. +failed: raising the db timeout changed nothing
  5. +guardrail: edit schema/api.yaml, never the generated client
  6. +open: does the cache explain the second path?

What it runs on.

MongoDB Atlas holds it. Secrets stay local.

  • $ stash init

    Joins your repo’s project.

  • $ stash push

    Captures this Claude Code session.

  • $ stash pull <id>

    Prints a Briefing for any agent.

  • $ stash merge <a> <b>

    Reconciles two sessions.
