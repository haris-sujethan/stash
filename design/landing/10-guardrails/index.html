How a rule is made.

Stash proposes. Only a person approves.

  • Seen in two sessions

    The same failed approach, in different sessions, checked against the evidence.

  • Proposed, not active

    A draft rule with its sources. No agent sees it yet.

  • Approved on the website

    By a human with the approver secret. The CLI cannot approve.

  • In every Briefing

    The next agent reads the rule before it starts.

A learned rule never weakens a security control. Agents cannot approve their own instructions.
