Every new session starts from zero. You explain the bug again. The agent rereads the same files, then retries what already failed.

How Stash works.

  1. Today, every session is an island.

    When a session ends, what the agent read, tried and decided ends with it.

  2. Push saves the session.

    What happened becomes memory in MongoDB Atlas, with secrets removed and evidence attached.

    stash push

  3. Pull powers the next agent.

    Any agent, on any model, gets a Briefing and picks up where the last one stopped.

    stash pull

  4. Merge joins two investigations.

    Two agents chased the same bug. Stash combines what both found and keeps where they disagree.

    stash merge

  5. Mistakes become rules.

    A failure seen twice becomes a proposed guardrail. Once a person approves it, every agent gets it.

What changes.

Less explaining. More building.

  • Never lose context

    Close the laptop, switch machines, come back next week. The work is still there.

  • Never repeat a dead end

    Failed approaches are saved, so the next agent skips them.

  • Switch models mid-task

    Start in Claude Code. Continue in another agent with the same context.

  • One memory for the team

    Your teammates’ agents build on what yours already found.

  • Claude Code pushesRun it inside your session.
  • Any agent with a shell pullsThe Briefing is plain text.
  • Stored in MongoDB AtlasSecrets never leave your laptop.
