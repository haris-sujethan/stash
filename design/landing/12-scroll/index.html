One memory for every agent.

Stash keeps what your coding agents learn. Nothing gets lost.

Install the CLIHow it works

Every session is an island.

Your agents work alone. When a session ends, what it learned is gone.

Push it to Stash.

One command saves the session: what was tried, what worked, what failed.

stash push

Stash remembers.

Every session joins one shared memory for the whole project.

Pull it anywhere.

Any agent, on any model, picks up exactly where the last one stopped.

stash pull

It gets smarter.

Mistakes made twice become rules every agent follows, once you approve them.

Every agent, one memory.

Claude Code, Codex or whatever comes next. They all build on each other.

What changes.

Less explaining. More building.

  • Never lose context

    Close the laptop, switch machines, come back next week. The work is still there.

  • Never repeat a dead end

    What failed is remembered, so the next agent skips it.

  • Switch models mid-task

    Start in one agent and finish in another, with the same context.

  • One memory for the team

    Your teammates’ agents build on what yours already found.

Never write a handoff.md again.
