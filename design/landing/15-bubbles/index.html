Every new session starts from zero. You explain the bug again. The agent rereads the same files, then retries what already failed.

How it works.

Your agents put what they learn in one place, and take it out anywhere.

  1. Push

    When a session ends, save what the agent learned: what it tried, what worked, what failed.

    stash push

  2. Pull

    Any agent, on any model, starts exactly where the last one stopped.

    stash pull

  3. Merge

    Two agents chased the same bug? Combine what both found, disagreements kept.

    stash merge

  4. Learn

    A mistake made twice becomes a rule you approve. Every agent follows it.

    stash guardrails

Git shares code. Stash shares the context behind it.

A handoff doc says what happened. Stash keeps how, why, and what failed.
