Your agents forget. Stash remembers.

Shared memory for AI coding agents, across sessions, models and teammates.

Install the CLIWhy Stash

  1. Every session starts from zero.

    Your agent spends an hour learning your codebase. The session ends, and all of it is gone.

  2. Push what it learned.

    One command saves the session: what it tried, what worked, what failed.

    stash push

  3. One memory, always growing.

    Every session, from every agent and every teammate, fills the same memory.

  4. Pull it into any agent.

    Claude, GPT or whatever comes next starts exactly where the last one stopped.

    stash pull

  5. Merge what two agents found.

    Two investigations become one. Disagreements kept, evidence attached.

    stash merge

  6. Learn from every mistake.

    A mistake made twice becomes a rule you approve. Every agent follows it.

Git shares code. Stash shares the context behind it.
